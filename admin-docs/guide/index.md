# Introduction

Admin Platform is an open-source admin platform built with Spring Boot, Vue 3, and TypeScript. It provides a reusable foundation for building business applications with separate frontend and backend projects.

## Core capabilities

| Area              | Features                                                         |
| ----------------- | ---------------------------------------------------------------- |
| System management | Users, roles, menus, and system configuration                    |
| Authentication    | Access control and online session management                     |
| Development tools | Scheduled tasks and template-based code generation               |
| Frontend          | Reusable components, theme preferences, and internationalization |

## Project structure

| Directory             | Purpose                                       |
| --------------------- | --------------------------------------------- |
| `admin-server`        | Backend entry point and runtime configuration |
| `admin-module-system` | System management and business features       |
| `admin-framework`     | Shared backend modules                        |
| `admin-ui`            | Vue frontend                                  |
| `admin-docs`          | This website and documentation                |

## Explore the project

- [Quick Start](./quick-start): run the backend and frontend locally.
- [Live Demo](https://admin-demo.geoearth.dev): explore the admin interface. The analytics and workspace dashboards use static demonstration data.
- [GitHub](https://github.com/geoearth-dev/admin-platform): browse the source, report issues, and contribute.
